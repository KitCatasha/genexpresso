# GenExpresso

GenExpresso is a Django web application for organizing and exploring gene-expression datasets from the [NCBI Gene Expression Omnibus](https://www.ncbi.nlm.nih.gov/geo/).

## Features

- User registration and authentication
- Project and dataset management
- GEO dataset retrieval using accession IDs
- Log2 transformation and data standardization
- Interactive heatmap, PCA and UMAP visualizations
- Processed-data export

## Technology

Python, Django, GEOparse, pandas, NumPy, scikit-learn, UMAP and Plotly.
